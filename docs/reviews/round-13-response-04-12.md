# 第 13 轮评审回应 · `04` 与 `12`

一行一条：条目 → 处理位置与方式。依据 `15` ADR-121 – ADR-127 与 `02`、`03` 的主干修订。

| 条目 | 处理 |
|---|---|
| R13-D4-02 | ADR-122：`04` §4.6.7 交还对话框第 6 步改为树级语义的三选一、无预选——以你的版本为准（整体置为你的副本，外部写入丢弃）/ 放弃你的改动（外部写入仍待采纳或撤销）/ 合并两者（仅路径不相交时可选，外部写入仍待决定）；写明任何选项都不会把外部写入算作你的改动；示例与规则同步 |
| R13-D4-03 | ADR-122：`04` §4.6.5 删除评审中“外部 · 待处置”hunk 与“采纳 / 撤销 hunk”按钮及其验收阻止项；新增 §4.8.7 `paused(external_change)` 卡片（事实列出路径，`采纳为我的改动` → 重新验证，`撤销这些改动` → 按路径恢复到归因基线、回到暂停前状态）；§4.18.3 对应行改为任何状态都先暂停；`12` 删除 `--diff-external-pending` 令牌与相关说明 |
| R13-D7-01 | `12` §12.6.5 `human_change_verify_failed` 文案注明只用于你的改动（含你显式采纳的外部改动），来源不明的内容不会走到这里；`external_change` 文案不推测来源；`04` §4.8.7 写明运行中收尾回合把外部路径记为 `author:"external"`、§4.8.8 写明存活进程的写入记在 Agent 名下 |
| R13-D8-01 | ADR-126：`04` 新增 §4.8.8 `bg_process_survived` 卡片（再次终止 / 知悉，标注与去重键）；`04` 中不存在“停止 Agent 的后台进程后继续”动作，并写明不提供此类动作的理由 |
| R13-D9-01 | ADR-126：`12` §12.6.4 新增 settle 收尾等待期实况行 `已停 · 收尾 · 等待后台进程 <剩余>/<总数>`，标为唯一定义；§12.6.3 `settled` 行引用它 |

| R13-D11-02（`04` 部分） | ADR-124：`04` §4.6.7 信任提示注明 base 中原有、未改动的不安全链接照常写出，仅列出 |
