# 第 65 轮评审回应

决策：ADR-193（`15` 末尾，L2581 起）；ADR-191、ADR-192 标题加 “Amended by ADR-193”；ADR-133 第 65 轮补记（`15` L1230）。本文件关闭 `round-65.md` §4 的 5 条（均为次要：D13 3 条、D7 1 条、D15 1 条）与 §5 的全部 13 条观察。行号为修改后的位置。

**收敛规则**（同 ADR-186–192）：只用三种办法关闭条目：
1. 把说法改弱，但保证为真；
2. 删除或推迟不属于 M1 主循环的机制；
3. 在已有的唯一定义处加至多一条守卫、一行或一个字段。

第 62–65 轮的条目都出在 Tower 写用户仓库的那一步，每补一条规则又带出新的边界。本轮不再逐条补规则，而是**缩小 M1 中 Tower 写用户仓库的范围**：
- 签名推迟到 M2；
- 撤销草案推迟到 M2；
- 以一条整体守卫避开用户进行中的 git 操作。

不新增状态、事件、表、命令或决定种类。新增的只有 `E_INTERNAL.detail.step` 的取值 `repo_busy`。“绝不碰用户的工作现场” 与全部安全不变式保持。安全问题只写到设计层面。
