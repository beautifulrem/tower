# 第 66 轮评审回应

决策：ADR-194（`15` 末尾，L2625 起）；ADR-193 标题加 “Amended by ADR-194”；ADR-133 第 66 轮补记（`15` L1236）。本文件关闭 `round-66.md` §4 的 5 条（均为次要：D13 2 条、D15 1 条、D4 2 条）与 §5 的全部 15 条观察。行号为修改后的位置。

**收敛规则**（同 ADR-186–193）：只用三种办法关闭条目：
1. 把说法改弱，但保证为真；
2. 删除或推迟不属于 M1 主循环的机制；
3. 在已有的唯一定义处加至多一条守卫、一行或一个字段。

每条在唯一定义处以一两句规则关闭，其余位置改为引用。不新增状态、事件、表、命令、决定种类或 `step` 取值；删去一个 M1 界面动作（放弃的撤销条与 `⌘Z`）。“绝不碰用户的工作现场” 与全部安全不变式保持。安全问题只写到设计层面。

**git 语义复核**（临时仓库，未触及项目仓库）：
- 在 base 上建 S₁、S₂，`merge --ff-only` 后执行 `git revert --no-edit <S₁ 的父>..<S₂>`：依次生成两个 revert 提交，base 的树与合入前相同。
- squash 合入两个 seal 的提交，其 patch-id 等于 `git diff <S₁ 的父> <S₂>` 的 patch-id，不等于 S₂ 自身的 patch-id。
- `../p1/wt`、`../p2/wt` 两个链接工作树的管理目录为 `wt`、`wt1`；后者 `worktree move` 到 `../moved` 后仍为 `wt1`，`worktrees/wt1/gitdir` 记录 `/…/moved/.git`。

## 偏离指示之处

- **R66-D13-02**：未采用 “读每个工作树 `.git` 文件的 `gitdir:` 行” 或 `git -C <路径> rev-parse --git-dir`，取评审给出的另一种：直接枚举 `<commonDir>/worktrees/*/`。
  - 它同样取自 git 自己的记录，不从路径推出目录名；
  - 还覆盖了手工移动、porcelain 只给出旧路径的工作树；
  - 不运行用户仓库中的命令。
- **R66-D4-01 (b)**：未采用 “并入 `externalChange`、撤销时转暂停”。在 `integrated` 中保存 `externalChange` 会违反现有 `CHECK`（`externalChange` 非空 ⇔ 暂停原因含 `external_change`）。改为宽限期内不检测、撤销后补一次检测，效果相同，且不新增转移。
- **R66-D15-01**：在评审的两种做法中取 “保留到影子删除”。另把 `10` 的保留期按 `06` 原有口径写作 “归档或放弃”，属于一处对齐，不是新规则。
- **观察 3**：除评审建议的 “patch-id 适用于任何非祖先情形” 之外，还把比较对象改为整段差异。原写法比较 seal 自身的差异：分支上有多个 seal 时，squash 合入判定不到，而只 cherry-pick 最后一个 seal 却会被误判为合入。
