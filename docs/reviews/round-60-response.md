# 第 60 轮评审回应

决策：ADR-188（`15` 末尾）；ADR-134、ADR-187 标题加 “Amended by ADR-188”。本文件关闭 `round-60.md` §4 的 5 条（重要 1、次要 4）、§5 的全部 11 条观察，以及 §3.1 建议的三项 lint。行号为修改后的位置。

**收敛规则**（同 ADR-186/187）：只用三种办法关闭条目：
1. 把说法改弱，但保证为真；
2. 删除或推迟不属于 M1 主循环的机制；
3. 在已有的唯一定义处加至多一条守卫、一行或一个字段。

本轮不新增状态、事件、表、命令或决定种类。新增的只有：`HumanDecision` 的一个字段 `integrate?`（存在已有的 `decisions.payload` 列中），以及 `prepare_failed` 的一个来源（`running`）。安全不变式全部保持，拿不准时取更严格的行为。安全问题只写到设计层面。

## Pi v1.2.0 引用

都已用 `git -C research/pi-mono show v1.2.0:packages/coding-agent/<path>` 核实：

- `src/core/extensions/loader.ts:289-300`：`registerTool` 在加载之后也可以调用（只做 `assertActive()`），写入后立即 `runtime.refreshTools()`。
- `src/core/agent-session.ts:3283-3306`（`bindExtensions`）：`:3304` 发出 `session_start`，`:3306` 执行 `extendResourcesFromExtensions`。
- `examples/extensions/dynamic-tools.ts:6, 51, 56`：在 `session_start` 中注册工具，也经运行期命令注册工具。
- `docs/extensions.md:183`：晚注册的扩展可以在自己的 `tool_call` 处理器中、调用执行之前完成注册（MCP 扩展即如此）。
- `src/core/agent-session.ts:668-674`：`tool_call` 事件只带 `toolName`，不带来源。
- `src/core/extensions/runner.ts:1249-1267`（`emitToolCall`）：按扩展顺序调用处理器，任一阻断即返回。
- `src/core/agent-session.ts:1498-1510`（`getAllTools`）：读 `_toolDefinitions`；`:3520-3553`（`_refreshToolRegistry`）：每次刷新都重建它。
- `src/core/extensions/runner.ts:636-646`：扩展工具先注册者胜，按扩展在列表中的位置，不按注册时间。
- **结论**：没有“最终工具列表”事件，也没有每回合的注册冻结点。gate 作为最后一个 `tool_call` 处理器，在调用时用 `getAllTools()` 看到的就是执行前的生效来源。因此采用“`bindExtensions` 之后自检 + gate 逐次复核”。
