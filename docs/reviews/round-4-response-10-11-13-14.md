# 第 4 轮评审回应 · `10` `11` `13` `14`（及 `16`）

每行一个条目：条目 → 处理方式与位置。

## 阻断

- **R4-D11-01** → ADR-071：
  - `10` §10.1.2 规定每次影子操作前用 Tower 自己的文件遍历扫描嵌套 `.git` 并以 pathspec 排除；影子索引中若已有 gitlink，先 `update-index --force-remove`，gitlink 永不进入影子索引；对嵌套仓库记 `nested_repo` 哨兵。§10.7.1 第 1 步同步。
  - GitRunner 运行在“只允许执行 git”的 OS 沙箱中（§10.1.2）；子模块在 M1 中排除（§10.14、§10.3.0）。
  - `11` T29 加入嵌套仓库与子模块，S0 残余风险改为高；`14` SP6b 新增 G9、G16。
- **R4-D11-02** → ADR-072：
  - `11` §11.6.2 规定卫星控制文件（含 `.git` 路径本身的重命名与删除）S2 写拒绝。
  - `10` §10.3.1 写明卫星创建时写入模板配置并记录 `controlHash`；settle、人工交接与 Run 开始前校验，不符则记 `git_control_tampered` 并从模板恢复。
  - Host 派生的子进程注入 `GIT_CONFIG_COUNT`，见 `11` T16/T29。
  - `14` SP6b 新增 G10（扩展执行 `pi.exec("git status")`）与 G11（“我来改”）。

## 重要

- **R4-D13-01** → ADR-073：
  - `10` §10.1 新增镜像库（从不 prune），卫星与影子的 alternates 改指镜像；删除用户仓库中的 base 保活 ref。
  - §10.16.2 改写情形 G（镜像被删时的恢复，用户维护不再触发该情形）；§10.17 改写对用户维护的表述；§10.16.3 bundle 改为基于镜像与影子。
  - `14` G12 为 cherry-pick + `gc --prune=now` 用例。
- **R4-D13-02** → `10` §10.14 的 LFS 行按 ADR-074 改为 M1 只读：复制用户全局配置中的 `filter.lfs.*` 驱动，GitRunner 沙箱允许执行 `git-lfs`，LFS 对象由镜像的 LFS 存储提供，影子中得到的是指针。`14` 新增 G13。
- **R4-D13-03** → `10` §10.3.0 增加添加项目时的检查（部分克隆不支持，浅克隆须先 unshallow），§10.14 新增对应行；`14` 新增 G14。
- **R4-D13-04** → 按 ADR-074，卫星创建后删除 `origin`，不保留任何远端（`10` §10.3.1）。Agent 侧 push/PR 在所有预设下为 forbid（`11` §11.2、§11.3.2；`10` §10.12）；在 M1 中子模块不初始化（§10.14）。`11` T5 写明 S0 下推送到用户仓库路径会被门禁按硬底线拦截。
- **R4-D11-03** → ADR-079：`11` §11.6.2 的网络行写明 srt 版本固定、`parentProxy`、PAC 单上游规则、仅支持 Basic 认证、Host 与 Supervisor 直接使用用户代理；新增 T30（中）；`14` SP6a 新增 A4–A7。
- **R4-D11-04** → `11` §11.3.3 第 3 条：用户检出只禁写、不禁读；`$TI`、镜像、`$SH` 加入硬底线。§11.3.4 中，密钥路径表适用于所有字符串参数（命中即 `secrets.access`，`readOnlyHint` 不再降级处理），无法确定基准的相对路径一律视为不透明参数（至少 ask）。
- **R4-D10-01** → ADR-075：`10` §10.1.2 与 §10.6 定义决定性指纹为“影子索引 + ctime/inode stat 检查”，完整重哈希只在验收与 seal 执行；`in_review` 期间改为文件系统事件驱动。`13` §13.1、§13.11.1–13.11.2 修正数字（无变化 ≤ 150 ms；重哈希按 SP5 实测），并重写永不降级的条目；`16` §16.2.6 同步。
- **R4-D4-01** → ADR-076：`10` §10.16.2 情形 E 改为唯一定义——任意非终态 → `paused(satellite_missing)`、记录 `resumeTo`、从影子中最新的检查点或 pin 重建、中性 `◇`、在 `in_review` 下先比较树再判 I2；情形 A、F 引用它。§10.3 状态图改为 `rebuilding`；§10.6 注明“卫星根目录消失”不作为指纹变化处理。
- **R4-D7-02** → `10` §10.4.2 与 `16` §16.8 规则 2 改为：版本识别顺序 `packageManager` → `devEngines` → PATH 探测并由人确认（锁文件版本不可用于区分）；Tower 工具缓存 `$SH/tools/pnpm@x.y.z` 放在 PATH 首位，设 `manage-package-manager-versions=false`，不依赖 Corepack。`14` 新增 P15、P17。
- **R4-D7-03** → `10` §10.4.2：yarn/bun 在 M1 按“生态未支持”处理；逐条标准的判定以 `07` §7.4.1 为准（先看是否有 exec 标准）。
- **R4-D7-04** → `10` §10.4.2“卫星侧的物化”与 `16` §16.8.1 新增一行：A 侧把 `.modules.yaml` 改写为 `$GS` store，兜底设 `confirm_modules_purge=false`。`14` 新增 P16。
- **R4-D7-05** → `10` §10.4.2 与 `16` §16.8.1 改为：
  - 安装命令带 `--ignore-scripts`，之后 pnpm 执行 `rebuild --pending`、npm 执行 `rebuild`（是否会执行根包脚本由 P17 核实）；
  - stage 与 `depsKey` 保留 `package.json` 中所有影响解析与构建的字段，并纳入项目 `.npmrc`；
  - 生命周期脚本的网络与超时规则以 `07` §7.4.3 为准；
  - `14` 新增 P19、P20。
- **R4-D8-01** → `10` §10.8.3 新增检验检出（ADR-078）；`14` §14.3.2 的映射与 W12a 纳入该项。
- **R4-D8-02** → `11` §11.3.1 的密钥路径表只包含未跟踪或被忽略的 env，被跟踪的 env 可读，读取时做密钥扫描；§11.6.2 新增“本地文件”行；三要素中的“私有数据”行已对齐。`10` §10.3.1 第 4 步播种本地文件。
- **R4-D14-01** → `14` §14.3.4 重写：
  - 修正 M0 算术（spike 7.2 + 骨架 6.3）；

  - 依赖链拆出 W9a/W9b 与 W12a/W12b，甘特图满足依赖并标注依赖；
  - 计入圣诞、新年与春节共 3 个节假日周；SP6c 移入 W8 的时间窗；W9 改为从影子检出 pin。
  - **M1 = 29 个日历周（2026-11-09 至 2027-05-28）**；若增加 1 人则为 25 周。
