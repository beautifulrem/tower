| 条目 | 处理 |
|---|---|
| R14-D7-01 #1 | ADR-128：`04` §4.8.7 卡片首行改为 ADR-128 原文（“……可能来自你的编辑器、其他程序，或未被追踪的 Agent 后台进程”），不再断言写入者 |
| R14-D8-01（`04` 部分） | `04` §4.8.7：重复检测并入同一张卡片（`ec:{goalId}`，基线保持首次值）；`external_change` 只在叠加原因中时照常出现并标“当前暂停原因：…”；标注与延迟代价按 ADR-128 |
| R14-D4-01 / 混合路径 | `04` §4.8.7：混合路径标 `◇ 同时有 Agent 的编辑`，撤销选项下警告“撤销会一并撤销 Agent 在这些文件上的编辑”；采纳后混合路径记 `mixed`；采纳 / 撤销后按 `detectedIn` 继续（含收尾序列中检测到的情形） |

| R14-D4-03 / ADR-129 | `04` 中不存在 Tower 提醒回合的界面；§4.19 写明 tower-goal 的常规提醒不是额外回合、不以你的身份发消息；新增“settle 后 2 秒内又有活动”行：目标仍显示“运行中”，不出现新状态 |
| ADR-128 远端合并 / ADR-132 ④′ | `04` F7 第 6 步：任何非终态观测到合入都进入 `integrated`，未处理的外部改动以“已过时”关闭、先做 safety 检查点并列入集成摘要；措辞同时覆盖“远端 PR 合并”与“M1 只保留分支、你在本地合入”两种情形 |
