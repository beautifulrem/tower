| 条目 | 处理 |
|---|---|
| R7-D4-01 (a) | ADR-099：`04` §4.6.7 “放弃改动”改为 `goal.discard_human_edits`——从评审接管且工作目录仍等于 pin 时直接回到评审（不触发 I2），否则回到接管前原因或最近一致状态；不会自行启动 Agent |
| R7-D4-01 (b) | ADR-099：`04` §4.6.6 第 6 步“作为人工改动带回目标”= `inspect.bring_back`，以 pin 为基线写回，进入 `verifying`（人的改动，失败不自动返工） |

| R7-D4-01 (d) | `04` §4.6.7 “编辑期间”：自动 rebase、机会式验证、合并队列暂停（队列中则出队），目标页一行说明 |
| R7-D8-01 (a) | `04` §4.6.7 交还对话框在有保留原因时显示 `◇ 交还后仍暂停：<原因>`，选项去向文字同步改写 |
| R7-D8-01 (b) | `04` §4.6.6 检验信任提示按 `10` §10.8.3 第 5 步重写：终端只带白名单环境，不含 shell 的其余环境（云凭据、*_TOKEN） |
