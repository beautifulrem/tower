## 偏离指示之处

- **R64-D13-01 未采用评审建议的 “S′ 写回影子作为 seal”**。
  - 采用的是按 “去掉签名头后逐字节相同” 识别，不增状态。
  - 写回会让 `seal/<n>` 指向一个只在用户仓库上下文中产生的对象，并多一次从用户仓库到影子的写入。
  - 签名在 git 中本来就定义为对 “去掉签名头的提交” 签名，两者等价；本方案只多一步生成后的校验。
- **观察 5 未改编号**。
  - SP6c 用例表占用 P1–P39，`13` 的任何 P 编号都会与之同号；P1–P8 早已同号（ADR-186 只写了说明）。
  - 换成一个不冲突的编号（P40 起）反而让 `13` 的编号不连续。
  - 因此改说明，并加 lint 防止今后漏写。
