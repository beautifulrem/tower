# 第 30 轮评审回应：`05`、`06`

以 ADR-156 为准。每条一行：条目 → 修订位置。

- R30-D13-01（凭据按主机、不清除用户 helper）→ `06` §6.2 GitService 行（L239）的网络命令通则：`credential.<scheme>://<host>.username`；只有 URL 带密码或 token 时才在用户 helper 之前追加 `store --file=<0600 文件>`（条目按主机）；从不清除用户的 helper 列表，URL 凭据从不原样写入临时配置；`GIT_CONFIG_NOSYSTEM=1` 只在写出完整有效配置时设置；认证类键读取用户检出的有效配置（含仓库级）。
