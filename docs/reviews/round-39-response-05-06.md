# 第 39 轮评审回应：`05`、`06`

以 ADR-165 为准。每条一行：条目 → 修订位置。

- R39-D11-01（本地文件中的机密）→ `06` §6.2 VerifierScheduler 行新增“本地文件的播种”：普通本地文件照常播种；含机密的本地文件（名字模式、用户标记或内容模式）在 M1 中不播种到验证槽位、检验检出或卫星，依赖它的检查写为 human 标准，设置页文案。`05` §5.10 `contextFiles` 行同步。
- R39-D11-02（注册表令牌）→ `06` VerifierScheduler 行的安装器编排：第 1 阶段只运行包管理器自身、禁用 pnpmfile 与生命周期脚本，令牌以 `~/.tower/run/<id>/` 即时投递文件提供、阶段结束即删，不再在 `~/.tower/installer/` 长期保存明文 npmrc；ADR-063 的“授予 Agent 可读的 npmrc”撤回（M2）。§6.6.1 `run/` 注释同步。`05` §5.3.1 脱敏集合与 §5.3.6 凭据行同步。
- 工具令牌 → `06` §6.6.1 “密钥”行：M1 钥匙串只存三类（模型提供商密钥、云 SDK 凭据、注册表令牌），工具令牌不导入；`05` §5.3.6 凭据行同步。
- R39-D15-01（`06` L293）→ §6.2.4：把 `startAgentActivity()` 一段移为独立段落，恢复“唯一闸口：自动返工、……”的句子结构。
- **自查修正**：`06` VerifierScheduler 行的“安装器编排”在第 34 轮改写机密段时被一并删掉（替换范围取到了该单元格末尾），本轮按原文恢复并加入 ADR-165 的第 1 阶段规则。
