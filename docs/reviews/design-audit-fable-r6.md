## 0. 总评

r5 的 Top 25 **落地 24 项**（唯一未动的是 #22"接受这个 hunk"），§2.9 的校对表也只剩"新的配对链接"一条。更重要的是这一轮第一次有了**能当海报的画面**：欢迎页的六站生命线 [11][12]、启动失败页"断电的仪表条"[14][15]、空概览的航班牌骨架 [08][09]。三个空 / 错误页终于不再长得一样，各自回答了"这里以后是什么"。决策卡上的保留测试输出用了"只给你看"的实线左栏 [16][22c]——这是 Tower 自己的语法又长出的一格。

它现在的位置：**桌面端放到 Linear 旁边已经不显得外行，而且开始有自己的脸。** 剩下的差距是三类——

1. **新面带来的新边角。** 概览简报行把 `已暂停（保留测试没有通过（Agent 看不到它们））` 写成双层括号，1100 宽时还折成两行 [03][06][10c]；手机页"为什么没开"那句说"在下面允许本地网络"，而复选框在它上面 [73b][73c]；保留测试卡的提示句 `max-width: 60ch` 在英文下孤行、◇ 悬在两行中间 [17][27]；无改动的评审页状态栏浮在屏幕 1/5 处、空态贴着窗口左缘 [58]。
2. **键盘用户看不见焦点落在哪个字段。** 字段焦点"只走边框"是对的，但边框从 10% 白到 16% 白的 1px 变化在截图里分辨不出 [22b]；探针量到聚焦后边框 alpha 0.10 → 0.10（过渡中）。这是本轮唯一的 H 级可达性问题。
3. **手机页的保留测试卡没有跟上桌面。** 桌面给了实线左栏、"只给你看"、提示框作主路径；手机上同一张卡是一个普通灰框、唯一的按钮是"放弃这个目标"、提示框没有占位文字排在最后 [82][89c][zh-80]。

D6–D8 修完 §4 的前 10 项可到 92–93；D9 这一轮从"没有一张画面"到"有三张"，再上去要的是让**每一个通用组件（toast、面板、手机卡）也说 Tower 的语法**。

## 2. 全局问题与修法

### 2.1 简报行：双层括号与 1100 折行

现状 [03][06][10c][zh-01]：概览顶部 `自 03:58 起 · G-0004 已暂停（保留测试没有通过（Agent 看不到它们）） · G-0003 待验收 · …`。`Overview.tsx:284-289 describe()` 用 `overview.pausedWith = "已暂停（{reason}）"` 包一层，而 `pause.held_out_failed` 自己就带括号。1100 宽时整行折成两行，`Since` 与 `03:58` 分家 [06]。

修法（S）：`describe()` 里对 `pauseLabel` 做一次"去尾括号"（或给 `pause.*` 另备一个短形：`保留测试失败`），简报只用短形；`.today-bar` 在 `max-width:1240px` 下 `white-space:nowrap; overflow:hidden`，每个 `.briefing-item` `max-width: 18em; text-overflow: ellipsis`，最多显示 3 项 + `还有 n 项`。

### 2.2 字段焦点不可见（H）

现状 [22b] + 探针 [P1]：Tab 四次落到保留测试卡的提示框，截图里分辨不出哪个字段有焦点。`app.css:882-894` 的规则是 `textarea:focus { border-color: var(--border-strong) }`、`textarea:focus-visible { outline:none }`——深色下 `--border` 0.10 → `--border-strong` 0.16 的 1px 变化，`input:focus-visible` 保留了 1.5px 环但 textarea 没有。决策卡、要求修改面板、steer 框、设置里的每个 textarea 都如此。

修法（S）：保留"字段焦点走边框"的原则，但让边框真的变：
```css
input:focus, textarea:focus { border-color: var(--text-3); }           /* 0.72 L：一眼可辨 */
textarea:focus-visible, input:focus-visible { box-shadow: inset 0 0 0 1px var(--text-3); outline: none; }
```
鼠标点进去是一道深边，键盘 Tab 进去是 2px 的同色边；面板首焦点仍不闪环。

### 2.3 手机问题句指错方向

现状 [73b][73c]：`Tailscale 没有连接，手机页面没有开启。打开 Tailscale，或在下面允许本地网络（…）`——句子在 `也在局域网上提供` 复选框**下面**（`Settings.tsx:382-394` 先、`:401-408` 后）。

修法（S）：把 `.phone-problem` 行挪到 `开启手机页面` 复选框之后、端口之前（问题在最上面，出路在它下面，句子就对了）；或改句为"或允许本地网络"去掉方位词（`lib.rs:435-436`）。前者更好：问题先于细节。

### 2.4 无改动的评审页

1. **动效与减动画仍无人公开做到。** 五级时序、四处减动画一致归零；Claude Code 桌面在 Reduce Motion 下工作指示器会卡住（#100485），Codex 评测说 FPS 掉到 10–15。
2. **主画面不是对话流，且空态也不是。** 空概览是一块航班牌骨架；Claude Code 的空态是"新会话页"，其余竞品没有可说的空态。
3. **诚实语法又长了一格。** `只给你看` 的实线栏、`Agent 不知道这些测试存在。给它提示能保住这一点；把失败给它看则不能`——没有任何竞品 UI 层区分"人能看到而 agent 不能看到"的证据。
4. **键盘注册表 + 中文。** 中文种子下整张卡是中文（本轮由监督器重发）；Claude Code zh-CN 仍是 issue，Conductor iOS 中文乱码，Codex i18n 在 flag 后面。
5. **错误页有脸。** 启动失败页是"断电的仪表条"；竞品的启动失败是一个对话框。

### 5.3 一句话定位

与 Codex / Claude Code / Conductor / Cursor 相比，Tower 在"按 hunk 接受、手机材质、可自定义"上落后半步，在"信息架构原创性、诚实语法、动效纪律、键盘与中文、空态与错误页"上领先一代。r5 的接缝缝上了，新面长出来了；留下的是一处 H（字段焦点）、三处新面的边角（简报行、手机问题句、无改动评审页）和一个次序问题（卡片先透明后折叠）。**它已经有三张能认出来的画面；要到 95，需要让通用组件也说同一种话。**

## 6. 要到 95，每个维度必须成立的事

**D6 页面 / 信息设计（90 → 95）**
- 每一句简报、每一句提示都只有一层括号、一个方位词指对地方（#3、#6）。
- 同一张卡在桌面与手机上同一层级：主路径在前、有名字（#4）。
- 评审的空态与别处同级，状态栏永远在底（#2）。
- 面板有查询时动作与目标分开（#15）；状态词是状态（#11）。

**D7 UI 视觉设计（90 → 95）**
- 焦点有两种形态且都看得见：控件一圈 1.5px、字段一道可辨的边（#1）。
- 任何注释行的字形对齐首行，没有孤行（#7）。
- 没有一个文字动作长得像正文（#9），没有一个列头读成一个词（#12）。
- 滚动容器的边有交代（#14）。

**D8 交互与动效（91 → 95）**
- 答完即折：卡片的离场与槽位的折叠是一件事（#5）。
- 评审动作成对：撤销 hunk 旁边有接受 hunk（#13）。
- 无一目标低于 20pt / 44pt（#8）。
- 嵌套 overlay 焦点归还有测试（#16）。

**D9 美学独特性（87 → 95）**
- 通用组件说 Tower 的语法：toast 的左缘、手机的骨架与刻度字距（#17、#18）。
- 一个可记住的转场：进评审时树滑入、diff 淡入（#19）。
- 仪表像仪表：运行环转到位，不跳变（#20）。
- 三张海报之外，第四张：手机页的空态或概览的"自上次看过"简报做成一行仪表读数，而不是一句话。
