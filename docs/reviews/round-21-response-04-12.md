# 第 21 轮评审回应 · `04` 与 `12`

一行一条：条目 → 处理位置与方式。依据 `15` ADR-147。

| 条目 | 处理 |
|---|---|
| R21-D4-01 `ready` 中的“我来改” | `04` §4.8.11：只在工作目录已存在（至少运行过一次）时出现，刚批准、从未运行的就绪目标不显示；补自就绪接管后放弃改动保持 `paused(human)`、就绪期间检测到外部写入进入 §4.8.7；`12` §12.6.5 `wait slot` 行同步 |
| R21-D4-01 准备阶段 | `04` §4.8.11 “正在启动”：准入通过到 Run 开始之间，暂停 / 我来改 / 放弃提示 `正在启动，稍后重试`（`E_BUSY`）；`12` §12.6.4 `preparing` 行同步 |
| R21-D4-02 返工计数 | `04` §4.8.11 与 F6 第 2 步：选择返工时 `返工 n/上限` 即加一，排队中也已计入，暂停或放弃不回退；排队卡片显示 `就绪 · 排队 · 第 1 位 · 返工 2/3`；`12` `wait slot` 行同步 |
| R21-D7-01（M2 `!cmd`） | 不涉及 `04`/`12` 的显示（混合路径的显示已在 §4.8.12） |
