## R75-D11-01（次要）：已解决

**唯一定义**：`16` §16.1.12“上下文文件名”一行（L287）。
- **名字集合**：Pi v1.2.0 的五个候选名，附出处。
- **比较规则**：按 `10` §10.1.2 的名字比较规则比较，与 `.git` 名字同一做法。这比评审建议的 “ASCII 大小写折叠” 更宽，也覆盖文件系统可能视为同名的非 ASCII 变体。
- 原有的 `**/AGENTS*.md`、`**/CLAUDE.md` 两个模式不收窄：按折叠后的 `agents*.md`、`claude.md` 匹配路径的最后一个分量，覆盖上述集合。
- 同一行列出用到它的四处。

**四处同步**：
- **S2 写拒绝**（`11` L350）：四个名字（`.pi`、`.agents`、`AGENTS*.md`、`CLAUDE.md`）都与 `.git` 一样，写为逐字符的大小写类。非 ASCII 等价变体不在沙箱规则内，由复核与 `protected` 兜底。
- **S2 读允许**：祖先上下文文件引用该行，规则写为大小写类。涉及 `11` L349、L30（`read.pi_resources`），`16` L251（§16.1.10 单一来源），`05` L446。
- **默认 `protected` 与分类器**：`02` L307–L308 注释；`11` L210。
- **上下文文件复核**（`11` L598）：对快照取完整的 `git diff --name-status`，再按名字规则筛选，不再用区分大小写的 pathspec。没有只换成 git 的 `:(glob,icase)`：已在本机验证它可用，但它只折叠 ASCII，与 `.git` 的比较规则不一致。

**其他同步**：
- `09` L450 的事实句改为引用该行（五个名字，以 `AGENTS.override.md` 为首；大小写不敏感的卷上任何变体都算存在；范围改为 agentDir 加祖先链）。

**观察 5 的取舍**：
- 只传内容、仍用 `systemPrompt` 不够：`resolvePromptInput` 会先对内容做 `existsSync`，内容恰好是某个存在的路径时，Pi 会读那个文件。
- 所以项目 `SYSTEM.md`/`APPEND_SYSTEM.md` 由 Supervisor 从 base 树读出内容，Host 经 `systemPromptOverride`/`appendSystemPromptOverride` 交给 Pi。这两个选项的返回值直接作为结果，不经“路径或文字”判定。
- 与 Pi 信任项目时一样，项目文件取代用户级同名文件、不合并。
- 内容在 Run 开始时固定，复核与加载之间文件消失也不会变成路径字符串。
- M2 的 `--system-prompt`/`--append-system-prompt` 同样经 `resolvePromptInput`，须传 Tower 自有、Agent 不可写的文件路径（记入 `11` L596）。
