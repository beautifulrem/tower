## 6. 补记：按 ADR-120 落地 U1–U3 后的复跑

主干在 ADR-120 中裁决了 §4 的三项。以下修改均为按 ADR 的机械同步。

### 6.1 U1 名字比较规则（唯一定义 `10` §10.1.2）

规则：**去除 Unicode 默认可忽略码位（`Default_Ignorable_Code_Point`）→ NFKC → 大小写折叠**；HFS+ 忽略的码位是其子集，因此不再是已知限制。

- `10` §10.1.2：改写为上述规则并声明为唯一定义；依赖目录名字扫描改为“按上文规则匹配”。§10.4.3 的 HFS+ 已知限制改为“已由该规则覆盖”。
- `07` §7.3.2：伪代码注释与 `norm` 改为“先去除，再 NFKC，再折叠”，即 `stripDefaultIgnorable(n).normalize("NFKC")`（原为 NFKC 之后再去除，顺序相反）；“前提”段改为只引用 `10`。
- 改为只引用 `10` §10.1.2、不再复述规则：
  - `05` §5.5、`06` §6.2.2；
  - `11` §11.6.2，以及 T29 与 T31（删除“HFS+ 已知限制”与“残余为 HFS+ 额外等价”）；
  - `16` §16.1.6 的 `nested_repo` 行与 §16.2.6；
  - `00` §0.5.1、`04` §4.6.2、`13` §13.11.1。
- `lint/xref.py` (r)：该概念的矛盾写法改为以下四种：
  - 省略“去除”一步的“NFKC + / 与 / 、大小写折叠”；
  - “NFKC 之后再去除”；
  - “HFS+ … 不覆盖 / 不在此规则内 / 已知限制”；
  - 代码 `stripDefaultIgnorable(x.normalize…)`。
  
  在临时副本中注入这几种写法，均能检出。
