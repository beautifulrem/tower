**收敛规则**（同 ADR-186–238）：只用三种办法关闭条目：
1. 把说法改弱，但保证为真；
2. 删除或推迟不属于 M1 主循环的机制；
3. 在已有的唯一定义处加至多一条守卫、一行或一个字段，其他文档引用而不复述。

**本轮的取向：按类关闭写回与可达性的问题。**
- **T1**：T1 从写回开始之前到写回成功一直被 ref 引用。于是任何出口——失败、中断、放弃，以及之后任何时刻——都不会使它不被引用，不再逐个出口补 “先保存”。
- **根**：根只由 Tower 在从未使用过时建立。于是 “根是否存在” 只由你决定，不再逐个建立根的步骤补守卫。
- **界面**：界面不提供会被拒绝的动作。

新增的只有：
- 检测器 id `tower_goal_handler_error`（kind `anomaly`）；
- `verify_env_error.stage` 的取值 `baseline`；
- `goal.delete_kept` 的可选参数 `handbackT1`。

不新增状态、暂停原因、事件类型、表、列、命令、决定种类、Needs-You kind、landmark、`wait_reason` 值、锁或进程。

安全不变式全部保留：
- Tower 不会自动把机密交给 Agent 可影响的进程。脱敏的覆盖面扩到 `details`。
- 根不可访问时，Tower 对任何 Goal 都不删除、不改名、不重建、不执行丢失处理，也不替你重新建立根。唯一的重建例外是 `project.relocate` 在已校验可访问的新根上的重建。
- 人的工作现场、`.kept-*` 与未写完的交还都不按时间删除（ADR-228 不变）。
- 清除从不写用户仓库；`project.relocate` 仍仅本机。

安全问题只写到设计层面。

## R111-D13-01（重要）：T1 在 `syncing` 期间不被引用；`handback-t1` 的期限与清除

唯一定义改到 `06` §6.4.3 `inspect.bring_back` 行 “T1 的保留”（L923）。

- **写入提前**：交还与带回在 T1 写入影子对象库之后、写 `syncing` 的事务之前，先写 `refs/tower/<goalId>/handback-t1`。

  - 落点：`06` L912（`goal.hand_back` ①）、L923（带回）。
  - 于是从写回开始到成功完成，T1 一直被引用：
    - 不可达多久、影子 gc 运行多少次，T1 都不被回收；
    - 卷回来时续写不缺对象。
- **只在写回成功时删除**：成功的事务提交之后删除。
  - 失败（①–④，含 ① 的物化也失败）、放弃与其他任何出口都不删除它。
  - **放弃不需要另写**，“放弃时写不成” 的情形随之消失。`06` L942 改为引用。
  - 成功提交之后、删除之前崩溃时它留下、照常列出，如实登记。

## R111-D13-02（次要）：Tower 自己重建缺失的根；情形 F 新根的记录时机

唯一定义在 `06` §6.1.6 Project 不可达一行（L139）。

- **Tower 不重新建立根**：
  - Tower 只在一个 `<wtRoot>` 中没有任何当前 `WorktreeRecord` 时建立它。
  - 只建立 Tower 自己命名的几级：`.tower-wt.noindex/<repoName>`，或 `worktreeRoot` 下的 `<projectId>`。
  - 上级目录（附着检出的父目录、你设置的 `worktreeRoot`）必须已存在且可访问，Tower 从不建立。
  - 卫星的 clone 在根已存在之后执行，所以 git 不会建立缺失的上级。
  - 其余情形下缺失的根就是不可访问的根，由你处理。
  - 引用处：`10` L361（clone）、L527（位置算法）、L1267（情形 F 的出口）。
- **新 Goal 从准备开始把将要使用的 `<wtRoot>` 计入必需路径**：
  - 根缺失或上级目录不存在时，它同样判为不可达，准备按 ② 中止、回到排队，卡片注明 `Project 不可达：<路径>`。
  - 不另设 `prepare_failed` 来源，复用已有的不可达处理与出口。
- **迁移的新记录先于重建**（`06` L921、`10` L1267）：
  - 新位置的 `goal` 角色 `WorktreeRecord`（`rebuilding`）与 `satellite_rebuilding=1` 在迁移的同一事务中写入。所以新根从此是必需路径，重建中途的崩溃与不可达都有续做者。
  - 迁移后的每个新 `<wtRoot>` 须可访问，或可按上述规则建立，否则 `E_STATE`。
  - `10` L42 同步。
- **验收**（`14` G35e）：
  - 补 “可达卷上删除整个 `<wtRoot>` 后新建 Goal” 一组；
  - 补 “迁移重建中途新根不可访问” 一组。
